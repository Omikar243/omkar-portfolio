# Omkar V Shettigar Portfolio

A responsive, single-page portfolio for Omkar V Shettigar — AI Engineer, ML Engineer and Data Scientist.

## Run

```bash
npm start
```

The site listens on port `3000` by default and serves the static portfolio from the project root.

## Personalization

Resume-based copy is in `index.html`. Theme, responsive layout, particles, loading, timeline reveals, navigation, case-study toast feedback, and contact-form validation are in `app.js` and `styles.css`.
