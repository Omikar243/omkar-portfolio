

## Approved cinematic direction

The hero will use a hybrid structure: the precise fractal tree and geometric O remain the identity anchor, while a larger layered depth world surrounds them. The experience may use pointer/touch-following light, scroll-driven cinematic scenes, parallax depth, draggable/orbiting stage objects, interactive 3D project cards, and reactive particles/branches. SIGNAL // ORBIT keeps its current game mechanics and accessibility behavior while receiving the same cinematic surface treatment.

The reference direction is Koi Mecha from Three UI: one coherent authored world, restrained procedural depth, tactile interaction, editorial navigation and cinematic scene transitions. This portfolio will not copy its private source or assets. It will use the existing Vanta/Three.js field, fractal canvas, GSAP/ScrollTrigger and local CSS/DOM depth layers so GitHub Pages remains viable and mobile performance stays bounded.

The ambient system is opt-in. It now crossfades between page-section scenes and visual themes, with low-pass filtering and visibility-safe suspension. Pointer/touch feedback may use short non-musical effects only after an explicit user gesture.


## Playground stability and cinematic refresh

The walkthrough review identified a scroll-ownership handoff around SIGNAL // ORBIT. Lenis was preventing the entire game article, so the page switched between Lenis and native scrolling depending on pointer location. The implementation now prevents Lenis only inside the canvas shell and disables conflicting CSS smooth-scroll behavior while Lenis is active.

The bloom control is a desktop-only progressive enhancement. It uses the existing scheduler, a low-resolution WebGL canvas, a persisted toggle/intensity setting and the existing ambient AudioAnalyser. Mobile, touch and reduced-motion sessions receive no bloom canvas. The cinematic refresh favors authored chapters, breathing room and stable continuous scroll over snap-scroll, using the existing precise tree/O as the visual anchor.


## Typography and pacing pass

The editorial hierarchy now uses fewer competing accents, stronger display scale, calmer support copy and larger breathing spaces between chapters. Project cards reveal as individual scroll beats rather than simultaneous blocks. SIGNAL // ORBIT keeps its render loop independent from expensive per-frame DOM writes; the HUD is updated at a low cadence while the canvas remains responsive. Pointer interaction is intentionally more visible through a moving spotlight, warm light shafts, a depth ring and composed card tilt.
