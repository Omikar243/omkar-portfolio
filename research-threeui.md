# Three UI reference notes

The Instagram reel by Codvyn describes four website references built around Three.js, 3D web design, AI, Claude Skills and ready-to-use UI components. The reel emphasizes distinctive interactive experiences rather than generic layouts.

Source: https://www.instagram.com/reel/Dd35bp-q_Cv/?utm_source=ig_web_copy_link&exln=MzRlODBiNWFlZA==&srtk=MzRlODBiNWFlZA==

The Three UI recent catalog includes authored experiences such as Noctiluca (slow-media descent with bioluminescent water and cursor-lit specimen plates), Kage (scroll scenes and a local Three.js world), Orrery (procedural orbital rings and drifting debris), Cortexa (point-cloud bust, data haze and pointer-following torch), and several cinematic motion studies. The relevant design direction is a coherent visual world with deliberate scroll choreography, restrained layered motion, focused cursor/touch response, responsive layouts and independently runnable components rather than unrelated decorative effects.

Source: https://threeui.com/browse?sort=recent

Implementation implication for this portfolio: keep the Renaissance tree/orbit identity, use a single coherent atmospheric system, synchronize ambient sound to the selected visual theme and visible page section, make transitions slow enough to feel cinematic but bounded for mobile performance, and preserve reduced-motion and explicit audio opt-in behavior.
